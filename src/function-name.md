# Nazwy funkcji

Przestrzegamy konwencji społeczności Go używającej konwencji [MixedCaps dla nazw funkcji](https://go.dev/doc/effective_go#mixed-caps). Wyjątkiem są funkcje testowe, które mogą zawierać znak podkreślenia w celu grupowania powiązanych przypadków testowych, np. `TestMyFunction_WhatIsBeingTested`.
